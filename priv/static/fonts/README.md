# Bundled fonts

DM Sans is used for body text; Outfit is used for headings and branding.
The variable WOFF2 files include Latin and Latin Extended subsets and are served
locally. Unsupported characters fall back to system fonts.

Both families are licensed under the SIL Open Font License 1.1. Their copyright
notices and licenses are included in `DM-Sans-OFL.txt` and `Outfit-OFL.txt`.
